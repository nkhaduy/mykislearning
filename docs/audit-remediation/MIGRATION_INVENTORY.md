# Migration inventory

This inventory follows lexical migration order. "Repeat-safe" means the SQL is
designed to tolerate a second validation execution; it does not authorize
rewriting Supabase migration history or marking an unapplied migration as run.

| Migration | Purpose and schema transition | Input dependency | Repeat-safe / data risk | Existing database compatibility |
| --- | --- | --- | --- | --- |
| `001_schema.sql` | Creates the original UUID/Auth schema: departments, profiles, courses, content, assignments, progress, quizzes, sessions, attendance, notifications, audit and storage metadata. | Empty Supabase database with `auth.users`, `auth.uid()` and `pgcrypto`. | Mostly `IF NOT EXISTS`; triggers/indexes are not uniformly guarded. No intended row deletion. | Establishes `profiles.id UUID -> auth.users` and `department_id UUID`; incompatible with Worker TEXT assumptions until `005`. |
| `002_rls.sql` | Enables RLS and creates UUID/Auth ownership and HR policies plus role helper functions. | Full `001` object set and `auth.uid()`. | Policy creation is one-time, not generally repeat-safe. No row mutation. | Functions compare UUID profile IDs to `auth.uid()`; `005` replaces affected semantics during conversion. |
| `003_external_training_and_employee_audit.sql` | Adds external training requests and employee profile audit logs using application account IDs. | Profiles/application account convention from the early app. | Additive tables/indexes; repeat-safe for objects. No destructive DML. | Mixed TEXT references foreshadow Worker schema but does not reconcile UUID FKs. |
| `004_core_learning_workflows.sql` | Adds user roles, external course submissions, learning history, certificates, file uploads and workflow policies/triggers. | UUID `profiles`, courses and Auth policies from `001-002`. | Mostly additive/upsert; policy/trigger statements are one-time. Backfills roles without deleting data. | Uses UUID FKs and is the last migration in the legacy UUID branch. |
| `005_cloudflare_missing_tables_patch.sql` | Bridges legacy UUID IDs to canonical TEXT, preserves `profiles.auth_user_id`, adds Worker profile/course/session fields, then creates missing Worker-era tables/indexes/functions. | Either the `001-004` UUID graph or a Worker database whose profile ID is already TEXT. | Conditional conversion and guarded object creation. UUID path rewrites tables/indexes and rebuilds public FKs under strong locks; no row deletion. | TEXT Worker databases skip conversion. Legacy Auth linkage remains nullable through `auth_user_id`; affected direct policies fail closed pending containment. |
| `006_worker_compatible_schema.sql` | Creates canonical Worker tables (`course_content`, `enrollments`, `content_progress`, training participants, quiz questions, etc.) and backfills legacy equivalents. | `005` profile/course compatibility shape. | Additive and deterministic `ON CONFLICT DO NOTHING` backfill. No legacy rows removed. | Safe for already-existing Worker tables; rerun does not duplicate deterministic IDs. |
| `007_hr_operational_overview.sql` | Adds activity heartbeat, HR task queue and operational overview structures. | TEXT profiles/Worker runtime. | Additive guarded schema. No intended data loss. | Compatible with Worker history; assumes TEXT account IDs. |
| `008_learning_history_certificates.sql` | Adds canonical learning records, attachments and certificate workflow structures. | TEXT profiles and Worker API conventions. | Additive, repeat-safe object creation. No destructive migration. | Becomes the target for reconciliation of legacy learning history/submissions. |
| `009_certification_reviewed_at.sql` | Adds certificate review timestamp. | `employee_certifications`. | `ADD COLUMN IF NOT EXISTS`; non-destructive. | Safe for all known histories containing the table. |
| `010_learning_paths.sql` | Adds learning paths, steps, assignments and progress. | TEXT course/profile/resource IDs and updated-at helper. | Additive guarded DDL. No row deletion. | Worker-only authorization model. |
| `011_compliance_training.sql` | Adds compliance programs, targeting, cycles, assignments and immutable completions. | Learning paths/courses and TEXT account IDs. | Additive guarded DDL. No row deletion. | Requires prior Worker schema. |
| `012_compliance_training_rls.sql` | Enables fail-closed RLS on compliance tables. | `011` tables. | RLS statements are repeat-safe; no policies granted to browser roles. | Preserves service-role Worker access and removes direct browser reachability. |
| `013_certificate_management.sql` | Adds certificate types/requirements and extends existing employee certifications. | Canonical certificate table from `008`. | Additive guarded DDL/backfill. No intended loss. | Reuses rather than duplicates certificate records. |
